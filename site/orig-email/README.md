Liens des modèles d'emails
================================

Les modèles d'emails pointent vers `/orig-email/<page>` plutôt que vers `/<page>` : ces adresses redirigent vers la vraie page. Sur GitHub Pages, rien n'est mesuré ; le jour où le site aura son propre hébergement, le serveur pourra compter les visites venues d'un email (sans cookie, anonymement), et les emails déjà envoyés seront comptés.

Un fichier par page d'atterrissage ; ne pas les supprimer, des emails envoyés y renvoient.
